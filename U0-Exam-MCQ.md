# U0-Exam-MCQ.md — AP Cybersecurity Practice Exam Multiple-Choice Questions

**Course**: AP Cybersecurity (ICA 2026-27)  
**Exam**: U0-Exam (Practice Exam)  
**Format**: 60 MCQs — 40 Single-Select + 20 Multi-Select  
**Time**: 80 minutes  
**LO Codes**: Per Course Curriculum Framework (`Unit.Topic.Letter`)

---

## Instructions

- **Single-Select**: Choose the ONE best answer (4 options: A–D)
- **Multi-Select**: Select ALL that apply (5 options, variable correct count) — marked with **[Multi-Select]**
- Each question tagged with its Learning Objective (LO) code
- Answer key with distractor analysis in **U0-Exam-MCQ-Key.md**

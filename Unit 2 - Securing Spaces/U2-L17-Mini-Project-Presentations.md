# U2 L17: Mini-Project Day 3 — Presentations (Oct 22, Thu — TECH DAY)

**⚡ HW Quiz (5 min):** 3 MCQ on risk treatment options (avoid/transfer/mitigate/accept) and the two words students mix up: mitigation reduces likelihood or impact, acceptance takes no action and retains the risk.

**Learning Objectives:**
- 2.1.E Assess risk using likelihood, impact, inherent vs residual risk
- 2.1.F Select a risk treatment option (avoid, transfer, mitigate, accept) and justify it
- 2.2.A Analyze tailgating and piggybacking as physical access attacks
- 2.2.B Analyze shoulder surfing as a physical information attack
- 2.3.A Evaluate locks and access controls for a given space
- 2.3.B Justify surveillance and CCTV placement
- 2.3.C Justify environmental and monitoring controls
- 2.4.A Explain what access/badge log monitoring can and cannot show
- 2.4.B Explain how video and log correlation identifies an attack
- 2.4.C Set an alerting threshold and name the response it triggers

**Materials:** Slides, presentation rubric (printed, one per student — included below), mini-project design doc and peer-review sheet from Days 1–2, timer on the projector, re-teach board

**Present today:** Group name, the space, then the plan. Five minutes, hard stop. Two minutes of Q&A from another group.

---

## Activities

1. **Setup and rubric walk-through (5 min):** Distribute the rubric and read the three scored rows aloud — threat model, layered controls, justification. Point out that the third row is where most groups lose points: naming a control is not a justification. A justification says what risk it reduces, and names the learning objective it satisfies.

2. **Presentations, round one (12 min):** Two groups present. 5 min each plus 2 min Q&A. Start the timer visibly — the hard stop is the point. The Q&A groups must ask at least one question that names a learning objective, not "what else would you do?"

3. **Presentations, round two (12 min):** Two more groups, same structure.

4. **Class vote and rubric feedback (10 min):**
   - Class votes for the strongest plan: show of hands per group, recorded on the board. The vote is not a grade — it is a signal about what the class found convincing.
   - Teacher returns rubric scores with one written comment per group, focused on the weakest row. Two or three groups get theirs read aloud anonymously so the whole class hears what a strong justification sounds like.

5. **Close — connect every choice back to an objective (6 min):** Walk the class through the objective list at the top of this file. For each objective, name one control some group proposed that satisfies it. The point to land: **every control in every plan traces to a learning objective.** If a group proposes a control that does not, that is the gap worth naming — either it does not reduce a risk we can name, or the group has not yet learned the objective it would satisfy.

   Then: the whole mini-project is the test's vocabulary. On Nov 13, a question will describe a space and ask for controls. You have already done this.

### Presentation rubric (Day 3)

Score each row 1–4. 4 = complete and specific, 3 = complete, 2 = thin or partly generic, 1 = missing or incorrect. Total 12.

| Row | What is scored | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| **Threat model** | The group names the assets worth protecting and the specific physical attacks against them (2.2.A–C), and at least one place where an attack begins physically. | No assets named | Assets named, attacks generic | Assets plus 1–2 specific named attacks | Assets plus specific attacks that trace to the space — a shared entrance, a reception desk, an unguarded closet |
| **Layered controls** | Controls cover more than one layer and more than one function — preventative, detective, corrective (see L03). At least one detective control. | Prevention only | Prevention plus one other function | Preventative, detective, and corrective all present | All three present, and the group can say which layer fails if the preventive layer is bypassed |
| **Justification** | Every control names the risk it reduces and the Unit 2 learning objective it satisfies (2.1.E, 2.1.F, 2.3.A–C, 2.4.A–C). | Controls named, no rationale | Rationale given without objective codes | Each control has a rationale and an objective code | Each control has a rationale, an objective code, and a stated effect on likelihood or impact (2.1.E) |
| **Q&A** (unscored) | Questions from other groups name a learning objective, not a preference. | No questions asked | Questions asked | Objective-named question | Objective-named question that exposes a real gap in the plan |

The **threat model** and **justification** rows are where points are lost. Name the weakest row in the written comment on every group's return.

**Homework (due Mon 20:30 — Oct 26 quiz):** The Unit 2 study guide, section 1: list every learning objective from the top of today's file, and next to each one write the single control you would build first. Do not write paragraphs — one line each. Bring it; Oct 26 opens with a quiz on it.

Presenting groups may use a slide outline instead of a deck. Timed stops apply to all groups, but Q&A may be run in written form for a group that prefers it — submit two questions instead of speaking.

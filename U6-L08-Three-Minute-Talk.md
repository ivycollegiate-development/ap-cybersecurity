# U6-L08: The Three-Minute Technical Talk

**AP Cybersecurity — ICA 2026-27**  
**Date**: May 17, 2027 (Mon) | **Period**: 129 | **Duration**: 50 min  
**Type**: Communication Skills | **Format**: Workshop + Practice

---

## Learning Objectives

By the end of this lesson, students will be able to:
1. **Structure** a 3-minute technical presentation: Problem → Approach → Result
2. **Translate** capstone complexity for mixed audiences (technical + non-technical)
3. **Deliver** with confident pacing, visual aids, and zero jargon without explanation
4. **Handle** Q&A with "I don't know, but here's how I'd find out"

## Lesson Flow

| Time | Activity | Details |
|------|----------|---------|
| 0-5 | **Why 3 Minutes?** | "Conference lightning talks, interview intros, stakeholder updates — all 3 min. Your capstone demo (U6-L13) is 3 min. Master this once, reuse forever." |
| 5-15 | **Structure Template** (10 min) | **Slide 1 (15s)**: Title + Name + Role Target + One-liner impact<br>**Slide 2 (30s)**: The Problem — visceral, quantified ("Hospital ransomware = $1.3M/day downtime")<br>**Slide 3 (45s)**: Your Approach — threat model insight + key technical decision<br>**Slide 4 (45s)**: The Result — demo screenshot, metric, "this detects X in Y ms"<br>**Slide 5 (30s)**: What's Next — known limitation + future work + ask<br>**Slide 6 (15s)**: Contact + GitHub + Portfolio QR code<br><br>**Rule**: 6 slides max. 30 pt font min. 1 idea per slide. |
| 15-25 | **Live Modeling** (10 min) | Teacher delivers 3-min talk on *sample* capstone (e.g., Lab 3 crypto extension). Students score on feedback form. Debrief: "What worked? What lost you?" |
| 25-40 | **Practice Rounds** (15 min) | **Round 1 (5 min)**: Solo — students rehearse to timer (phone), record audio<br>**Round 2 (5 min)**: Pairs — deliver to partner, partner times + feedback form<br>**Round 3 (5 min)**: Volunteers (2-3) deliver to class; class gives feedback form |
| 40-48 | **Q&A Drill** (8 min) | "The question you dread." Students write 1 feared Q on card. Teacher reads; student practices: "Great question. I didn't explore that, but I'd start by [method]. Here's what I *do* know: [related finding]." |
| 48-50 | **Commit Slide Deck** | Export slides to `demo/slides.pdf` in portfolio repo. `git add demo/slides.pdf && git commit -m "Add 3-min talk slides" && git push` |

---

## Teacher Notes

- **Timing is everything** — 3:00 ± 15 seconds. Practice with timer visible.
- **Audience awareness**: Assume 1 security engineer + 1 hiring manager + 1 HR
- **No reading slides** — speaker notes separate
- **Demo integration**: Slide 4 *is* the demo moment (screenshot or 30-sec clip)

---

## Differentiation

| Need | Adjustment |
|------|------------|
| Public Speaking Anxiety | Practice 1:1 with teacher first; allow notes; focus on structure over polish |
| ELL | Provide script template; allow bilingual slides (English + Chinese key terms) |
| Advanced | Add: "Handle hostile Q&A" — "Your threat model missed X" → "Valid. We scoped Y. Here's why..." |

## LO Code Format (Verified from CED)

**Pattern**: `Unit.Topic.Letter` (e.g., `1.1.A`, `2.1.A`, `3.1.A`, `4.1.A`, `5.1.A`)

- **Unit**: 1–5
- **Topic**: 1–6 (varies by unit)
- **Skill/LO Letter**: A, B, C, D, E, F, G (sequential per topic)

**Examples from CED**:
- `1.1.A` Identify common indicators of social engineering tactics
- `2.1.A` Identify social engineering attacks
- `2.1.B` Identify types of adversaries
- `3.1.A` Identify common network attacks
- `4.1.A` Identify types of computing devices
- `5.1.A` Explain how adversaries can exploit application and file vulnerabilities

## FRQ Specification (Official)

**Task**: Device Security Analysis  
**Format**: 5 parts (A–E), 14 points total  
**Sources provided**: Firewall configurations, authentication logs, file-system permissions, web server logs, network application logs  
**Skills assessed**: Mitigate Risk (2) & Detect Attacks (3)  
**Task verbs**: Identify, Explain, Describe, Determine, Write  
**Time**: 50 minutes

| Multi-Select | "Select all that apply — 5 options, variable correct count" | ~20 of 60 MCQ (per plan + CED sample) |

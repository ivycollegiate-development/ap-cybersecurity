# U6-L13: Portfolio Presentations — Capstone Showcase

**AP Cybersecurity — ICA 2026-27**  
**Date**: May 28, 2027 (Fri) | **Period**: 134 | **Duration**: 50 min  
**Type**: Summative Presentation | **Format**: 3-min Talks + Q&A

---

## Learning Objectives

By the end of this lesson, students will be able to:
1. **Deliver** a polished 3-minute technical presentation on their capstone project
2. **Demonstrate** live or recorded proof of implementation
3. **Respond** to technical questions with depth and honesty
4. **Celebrate** the completion of AP Cybersecurity portfolio journey

---

## Prerequisites

- Portfolio complete and public (PORTFOLIO.md all sections, repo polished)
- 3-min talk slides finalized (`demo/slides.pdf`)
- Demo recording ready (`demo/demo.mp4`) or live demo rehearsed
- Peer review revisions committed (U6-L12)

---

## Materials

- Presentation schedule (randomized order, posted day before)
- Timer (visible, strict 3:00 ± 15s)
- Portfolio-Rubric.md Dimension 4 scoring sheets (teacher)
- Feedback forms (peer audience)
- Recording device (for student portfolio)

## Teacher Notes

- **Scheduling**: Randomize order day before; post on Classroom. Allow volunteers to go first.
- **Audience**: Invite admin, CS department colleagues, parents (optional) — raises stakes
- **Recording**: Each student gets their talk recorded → portfolio artifact
- **Scoring**: Teacher scores Dimension 4 live; Dimensions 1-3, 5-6 pre-scored from portfolio review
- **Light Option students**: Present threat model + pseudocode + test plan — same 3-min format

---

## Differentiation

| Need | Adjustment |
|------|------------|
| Presentation Anxiety | Offer: present to teacher only (recorded) during lunch; same rubric |
| ELL | Allow bilingual slides; extra 30s; teacher prompts if stuck |
| Technical Issues | USB backup required; teacher has spare laptop/projector |

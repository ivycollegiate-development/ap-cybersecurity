## 1: Think-Pair-Share — Threat Profiles

Your pair is assigned ONE adversary category. Build a detailed threat profile, then present to the class. Everyone fills in all six boxes as the presentations happen.

**The six adversary categories:**
1. Script kiddies — low skill, opportunistic, using existing tools
2. Hacktivists — political/social motivation, website defacement, data leaks
3. Insider threats — employees/contractors, authorized access abused
4. Cyberterrorists — critical infrastructure, mass disruption
5. Transnational criminal organizations — financial motivation, ransomware, fraud
6. State adversaries — espionage, intellectual property theft, advanced persistent threats

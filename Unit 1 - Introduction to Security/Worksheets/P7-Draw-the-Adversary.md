# Draw the Adversary — Matching Cards

**Instructions:** Six cards below describe fictional adversary characteristics. Match each card to ONE of the six adversary categories. Then, for your assigned pair, write a one-sentence threat profile (motive → target → methods).

## The Six Adversary Categories
1. **Script Kiddie** — low skill, opportunistic, uses existing tools
2. **Hacktivist** — political/social motivation, defacement, data leaks
3. **Insider Threat** — employee/contractor, abuses authorized access
4. **Cyberterrorist** — critical infrastructure, mass disruption
5. **Transnational Criminal Org.** — financial motivation, ransomware, fraud
6. **State Adversary** — espionage, IP theft, advanced persistent threat (APT)

## Teacher Notes

- **Check-in focus**: Unblock, don't write. Ask: "What's the evidence for this claim?" "Where's the LO code?"
- **Light Option students**: Threat model + pseudocode + test plan → same sections, adjusted expectations (Rubric: Light Option max 60/100)
- **Codespaces**: Ensure all have devcontainer running for live preview
- **Time**: This is *draft* — perfection not expected; Build Day 2 = polish

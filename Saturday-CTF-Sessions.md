## Session format (2-3 hrs, single block)

1. Warm-up challenge (15 min)
2. Main challenge arc (90 min) — student drives, Paul coaches
3. Writeup time (30 min) — GitHub repo under `ivycollegiative-development`,
   one writeup per session: what the challenge was, failed attempts included,
   what worked, why. Reviewed in person same day.
4. Next-session preview (5 min)

## Why this matters (the portfolio thesis)

One writeup per session × ~15 sessions = a public GitHub history by May that says
"this person does security for fun." Combined with the free Security+ voucher via
College Board Kickstart (3+ AP score), this student exits with exactly the
judgment-plus-cert stack the Credential Ladder describes — and a 1:1 mentorship
story that is next year's enrollment marketing.

# U6-L05: Career Paths — Analyst, Engineer, Incident Response, Research

**AP Cybersecurity — ICA 2026-27**  
**Date**: May 12, 2027 (Wed) | **Period**: 126 | **Duration**: 50 min  
**Type**: Career Exploration | **Format**: Panel Simulation + Role Comparison

---

## Learning Objectives

By the end of this lesson, students will be able to:
1. **Compare** day-to-day responsibilities across 4 major career tracks
2. **Match** their capstone skills to role requirements (skills gap analysis)
3. **Identify** which track aligns with their interests and aptitudes
4. **Articulate** a "why this track" narrative for interviews and essays

## Lesson Flow

| Time | Activity | Details |
|------|----------|---------|
| 0-5 | **Framing** | "You have skills (capstone), a plan (certs), a portfolio (GitHub). Now: *where do you fit*?" Tracks aren't silos — people pivot. |
| 5-20 | **Panel Simulation: 4 Tracks** (15 min) | Teacher role-plays 4 professionals (or use pre-recorded 2-min videos):<br>1. **SOC Analyst L2** — "I triage 200 alerts/day. Best part: catching real attacks. Worst: alert fatigue. Key skill: Splunk + MITRE mapping."<br>2. **AppSec Engineer** — "I review PRs, run SAST, teach devs secure coding. Best: fixing before prod. Worst: 'it works on my machine' pushback. Key skill: code review + threat modeling."<br>3. **Incident Responder** — "I get called at 3 AM. Best: the puzzle, the impact. Worst: burnout, travel. Key skill: log analysis + memory forensics + communication."<br>4. **Security Researcher** — "I hunt vulns in open source. Best: CVEs, recognition. Worst: long dry spells, responsible disclosure friction. Key skill: fuzzing, code audit, exploit dev." |
| 20-35 | **Role Comparison Worksheet** (15 min) | Students complete for each track:<br>| Dimension | SOC Analyst | AppSec Engineer | IR Responder | Security Researcher |<br>|---|---|---|---|---|<br>| **Daily Work** | | | | |<br>| **Tools** | | | | |<br>| **Certs Valued** | | | | |<br>| **Entry Barrier** | | | | |<br>| **My Capstone Maps To** | | | | |<br>| **Interest (1-5)** | | | | | |
| 35-43 | **Skills Gap Analysis** (8 min) | For top 2 tracks of interest:<br>1. List 5 required skills from worksheet<br>2. Rate current proficiency (1-5) from capstone + coursework<br>3. Identify top 2 gaps<br>4. Map gaps to: cert study, portfolio project, CTF, coursework |
| 43-48 | **Narrative Draft** (5 min) | Write 3-sentence "Why [Track]?" for interviews:<br>"I chose [Track] because [capstone experience] showed me [specific skill/interest]. My [cert/portfolio/CTF] proves I can [key competency]. I'm targeting [specific role] at [company type]." |
| 48-50 | **Share & Commit** | Volunteers share narrative. Teacher notes: tracks chosen, gaps identified. |

## Part 1: Role Taxonomy

### Major Cybersecurity Career Tracks

| Track | Primary Focus | Typical Entry Roles | Mid-Career | Senior/Lead |
|-------|---------------|---------------------|------------|-------------|
| **Security Operations (SecOps)** | Monitoring, detection, response | SOC Analyst L1/L2, Threat Hunter | Senior Analyst, Detection Engineer | SOC Manager, Threat Intel Lead |
| **Application Security (AppSec)** | Secure SDLC, code review, WAF | AppSec Analyst, DevSecOps Engineer | Senior AppSec Engineer, Security Architect | AppSec Manager, Chief Product Security Officer |
| **Cloud Security** | AWS/Azure/GCP hardening, CSPM | Cloud Security Engineer | Senior Cloud Security Engineer | Cloud Security Architect |
| **Incident Response (IR)** | Breach response, forensics, recovery | IR Analyst, Digital Forensics Examiner | Senior IR Consultant, Malware Analyst | IR Manager, CISO Office |
| **Governance, Risk, Compliance (GRC)** | Policy, audit, regulatory | GRC Analyst, Compliance Analyst | Senior GRC Manager, Privacy Officer | CISO, Chief Risk Officer |
| **Offensive Security** | Pen testing, red team, exploit dev | Penetration Tester, Red Teamer | Senior Pen Tester, Red Team Lead | Offensive Security Manager |
| **Security Engineering** | Tool building, automation, platforms | Security Engineer, Detection Engineer | Senior Security Engineer, Platform Engineer | Security Engineering Lead |

### Cross-Cutting Specializations
- **Identity & Access Management (IAM)**: Okta, Azure AD, PAM, Zero Trust
- **Data Security**: DLP, encryption, key management, privacy engineering
- **OT/ICS Security**: Industrial control systems, SCADA, critical infrastructure
- **Product Security**: Bug bounty triage, vulnerability disclosure, SDL
- **Security Research**: Vulnerability research, exploit development, threat intelligence

## Part 2: Certification Ladder

### Entry Level (0-2 years experience)

| Cert | Vendor | Cost | Time | Focus | ROI Notes |
|------|--------|------|------|-------|-----------|
| **CompTIA Security+** | CompTIA | ~$400 | 2-3 mo | Foundations, broad coverage | **Best first cert** — DoD 8570 baseline, widely recognized |
| **(ISC)² CC** | (ISC)² | ~$199 | 1-2 mo | Foundational concepts | Newer, less recognized than Security+ |
| **GIAC GSEC** | GIAC | ~$949 | 3-4 mo | Hands-on technical | Higher cost, more technical depth |

### Associate Level (1-3 years)

| Cert | Vendor | Cost | Time | Focus | Prereq |
|------|--------|------|------|-------|--------|
| **CompTIA CySA+** | CompTIA | ~$400 | 2-3 mo | SOC, threat detection, SIEM | Security+ recommended |
| **CompTIA PenTest+** | CompTIA | ~$400 | 2-3 mo | Pen testing, vuln mgmt | Security+ recommended |
| **(ISC)² SSCP** | (ISC)² | ~$250 | 3-4 mo | Ops, admin, technical | 1 yr experience |
| **GIAC GCIH** | GIAC | ~$949 | 3-4 mo | Incident handling | None |

### Professional Level (3-5 years)

| Cert | Vendor | Cost | Time | Focus | Prereq |
|------|--------|------|------|-------|--------|
| **(ISC)² CISSP** | (ISC)² | ~$749 | 4-6 mo | Broad management + tech | 5 yrs exp (2 domains waived w/ degree) |
| **ISACA CISM** | ISACA | ~$760 | 3-4 mo | Management, governance | 5 yrs exp (3 management) |
| **ISACA CISA** | ISACA | ~$760 | 3-4 mo | Audit, control | 5 yrs exp |
| **OffSec OSCP** | OffSec | ~$1,599 | 3-6 mo | Hands-on pen testing | **Gold standard** for offensive |
| **GIAC GPEN/GXPN** | GIAC | ~$949 | 4-5 mo | Pen testing / exploit dev | None |

### Specialty / Advanced (5+ years)

| Cert | Vendor | Focus |
|------|--------|-------|
| **CISSP Concentrations** (ISSAP, ISSEP, ISSMP) | (ISC)² | Architecture, Engineering, Management |
| **CCSP** | (ISC)² | Cloud security |
| **OSCE/OSWE/OSEE** | OffSec | Advanced exploit dev, web, evasion |
| **GSE** | GIAC | Expert-level (requires multiple GIACs) |

### Vendor-Specific (Cloud)

| Cert | Vendor | Level | Notes |
|------|--------|-------|-------|
| **AWS Security Specialty** | AWS | Professional | Requires Associate first |
| **Azure Security Engineer (AZ-500)** | Microsoft | Associate | Strong enterprise demand |

## Part 4: Employer Expectations (What They Actually Ask)

### Resume Screening Keywords (from 50+ job postings analysis)

| Category | Top Keywords |
|----------|--------------|
| **Tools** | Splunk, Elastic, CrowdStrike, SentinelOne, Wazuh, Burp Suite, Nmap, Metasploit, BloodHound, Terraform, Ansible |
| **Cloud** | AWS (GuardDuty, Security Hub, IAM), Azure (Defender, Sentinel), GCP (SCC) |
| **Frameworks** | NIST CSF, MITRE ATT&CK, OWASP Top 10/ASVS, ISO 27001, SOC 2, PCI-DSS |
| **Languages** | Python (automation), Go (tools), Bash, PowerShell, JavaScript (Node), Rust (emerging) |
| **Practices** | CI/CD security, IaC scanning, SAST/DAST/SCA, threat modeling, Zero Trust, SBOM |

### Interview Formats by Role

| Role | Technical Screen | Deep Dive | Practical |
|------|------------------|-----------|-----------|
| SOC Analyst | Alert triage scenario | SIEM query writing | Mock investigation (PCAP/logs) |
| AppSec Engineer | Code review exercise | Threat model a design | SAST/DAST tool config |
| Pen Tester | Web app vuln walkthrough | Network pivot scenario | Live hack (HTB/TryHackMe style) |
| Security Engineer | System design (auth, logging) | Tool selection justification | Scripting challenge (Python/Go) |
| GRC | Policy gap analysis | Control mapping exercise | Audit simulation |

### What Employers **Don't** Ask For
- ❌ "List all ports" (memorization)
- ❌ "Define CIA triad" (basic definitions)
- ❌ Degree from specific university (unless government)
- ❌ Number of certs (quality > quantity)

### What Employers **Do** Ask For
- ✅ "Walk me through a real incident you handled"
- ✅ "Show me your GitHub — explain this project"
- ✅ "How would you threat model this architecture?"
- ✅ "You see X alert — what's your first 3 queries?"
- ✅ "Explain a vuln you found and how you fixed it"
